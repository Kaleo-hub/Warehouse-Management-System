# 08 · 表字段速查手册

> 配套 `07-数据库表结构笔记.md`。那份讲**设计思路**，这份讲**字段事实**。
> 数据来源：`db/migration/V1.0.0 ~ V1.0.7`。共 **21 张表**。
>
> 字段表说明：「空/默认」列写 `NOT NULL` 表示必填无默认值；写 `NULL` 表示可为空。
> 时间列统一 `datetime(3)`（毫秒精度），本手册简写为 `dt3`。

---

## 一、主数据层

### 1. `sys_user` · 系统用户

| 字段 | 类型 | 空/默认 | 说明 |
|---|---|---|---|
| `id` | bigint unsigned | NOT NULL AI | 主键 |

| `deleted` | tinyint | NOT NULL `0` | 逻辑删除 |

**索引**：`PRIMARY(id)`、`UNIQUE uk_username(username)`

## 二、库存核心层

### 7. `inventory` · 库存余额 ★核心

| 字段 | 类型 | 空/默认 | 说明 |
|---|---|---|---|
| `id` | bigint unsigned | NOT NULL AI | 主键 |
| `warehouse_id` | bigint unsigned | NOT NULL | 仓库 |
| `location_id` | bigint unsigned | NOT NULL | 库位 |
| `sku_id` | bigint unsigned | NOT NULL | 商品 |
| `batch_no` | varchar(64) | NOT NULL `''` | 批次号；无批次用**空串**（NULL 会破坏唯一约束） |
| `qty` | int | NOT NULL `0` | 在库实物数量 |
| `locked_qty` | int | NOT NULL `0` | 锁定数量（已分配未出库） |
| `frozen_qty` | int | NOT NULL `0` | 冻结数量（盘点/质检） |
| `available_qty` | int | **生成列 STORED** | `qty - locked_qty - frozen_qty`，只读 |
| `version` | int | NOT NULL `0` | **乐观锁版本号** |
| `production_date` | date | NULL | 生产日期，用于 FIFO |
| `expiry_date` | date | NULL | 到期日期 |
| `inbound_time` | dt3 | NULL | 首次入库时间，用于 FIFO，**只写一次** |
| `deleted` / 审计字段 | — | 同通用 | |

**索引**：
- `UNIQUE uk_loc_sku_batch(location_id, sku_id, batch_no)` ← 系统粒度基准
- `idx_sku_wh(sku_id, warehouse_id)`
- `idx_fifo(sku_id, warehouse_id, inbound_time)` ← FIFO 拣货
- `idx_location(location_id)`
- `idx_available(sku_id, warehouse_id, available_qty)` ← 分配时筛可用量

**约束**：`chk_inventory_qty` — 三量均 >= 0 且 `locked_qty + frozen_qty <= qty`

**索引**：`UNIQUE uk_tx_no(tx_no)`、`idx_sku_time(sku_id, create_time)`、`idx_source(source_type, source_id)`、`idx_location_time(location_id, create_time)`、`idx_biz_time(create_time)`

### 13. `outbound_allocate` · 出库库存分配明细 ★

一行 = 某单据明细占用了某条 inventory 的多少数量。**"锁定"的载体。**

| 字段 | 类型 | 空/默认 | 说明 |
|---|---|---|---|
| `id` | bigint unsigned | NOT NULL AI | 主键 |
| `order_id` | bigint unsigned | NOT NULL | 出库单 ID |
| `order_item_id` | bigint unsigned | NOT NULL | 出库单明细 ID |
| `inventory_id` | bigint unsigned | NOT NULL | 锁定的库存记录 ID |
| `warehouse_id` / `location_id` / `sku_id` | bigint unsigned | NOT NULL | 冗余固化，避免 join、也防移库改掉 |
| `batch_no` | varchar(64) | NOT NULL `''` | 批次号 |
| `allocated_qty` | int | NOT NULL `0` | 分配数量 |
| `picked_qty` | int | NOT NULL `0` | 已拣货数量 |
| `status` | varchar(20) | NOT NULL `LOCKED` | `LOCKED` / `PICKED` / `RELEASED` |
| `deleted` / 审计字段 | — | 同通用 | |

**索引**：`idx_order`、`idx_order_item(order_item_id)`、`idx_inventory(inventory_id)`、`idx_status(status)`
**约束**：`chk_allocate_qty` — 两数量 >= 0
**配套动作**：分配 → `inventory.locked_qty += N`；拣货 → `locked_qty -= N, qty -= N`

### 19. `sys_sequence` · 单号发号器（V1.0.1）

⚠️ **没有 `id` 列**，复合主键 `(biz_type, biz_date)`。也没有 `deleted`/`create_by` 等。

| 字段 | 类型 | 空/默认 | 说明 |

| `current_value` | bigint | NOT NULL `0` | 当前已发到的序号 |
